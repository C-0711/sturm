# STURM — sturm.wtf

> Gegen Zensur. Für Souveränität. Gegen Kontrolle durch Konzerne und Staaten.
> Against censorship. For sovereignty. Against control by corporations and states.

Ein kollaboratives Wiki, das belegte Fälle von Zensur, Sprachkontrolle und Überwachung sammelt — und zeigt, wie man unabhängig wird. **Jeder Artikel ist ein Dossier: Behauptung → Beleg → Zeitleiste → Lügen ausräumen → Quellen.**

## Mitmachen

- **Fehler melden:** [Issues](https://github.com/C-0711/sturm/issues) — wir korrigieren alles, was belegt ist.
- **Fall beitragen:** PR nach dem Dossier-Standard in [CONTRIBUTING.md](CONTRIBUTING.md).
- **Übersetzen:** DE/EN sind vollständig; FR/ES/PT brauchen dich.
- **Diskutieren:** [Discussions](https://github.com/C-0711/sturm/discussions).

Der Initiator nennt sich **Mastermind** — absichtlich ohne Namen und Links zu einer Person. Dieses Projekt wird nach seinen Argumenten und Belegen beurteilt.

## Regeln

1. **Keine Zeile ohne Quelle.** Jede Zahl datiert und verlinkt.
2. **„Lügen ausräumen" ist Pflicht** — auch gegen die eigene Position. Ein Dossier, das nur eine Seite bestätigt, ist Propaganda.
3. **Keine Parteinahme.** Zensur von links, rechts, staatlich, privat — alles kommt vor, wenn belegt.
4. **Keine Verschwörungsbehauptungen ohne Beleg.** „Zeig die E-Mails, den Gerichtsbeschluss, den Investigativbericht."

## Technik

Jekyll auf GitHub Pages. Statisch, keine Tracker, keine Cookies, keine externen Fonts/CDNs. CSS und JS sind inline aus diesem Repository.

Lokal bauen:

```bash
bundle install
bundle exec jekyll serve
```
